# Neil Patterson — Resume

**PDF:** [Latest resume](resume.pdf) · [All versions](versions/)

This repository contains the source for my resume as a single Awesome-CV LaTeX document. 

The document uses [Awesome-CV](https://github.com/posquit0/Awesome-CV), with the class and fonts kept in the repository so the build does not depend on a checkout of the upstream project. `awesome-cv.cls` is an explicitly marked local modification of the upstream class; its original attribution and LPPL license are preserved in the file and in `AWESOME-CV-LICENCE`.

The resume content is my own. The template layout and class are not presented as original work.

## Dependencies

Install a TeX distribution with XeLaTeX and the packages used by Awesome-CV.

### macOS

Install [MacTeX](https://www.tug.org/mactex/). It includes XeLaTeX and the required packages.

### Debian / Ubuntu

```sh
sudo apt install texlive-xetex texlive-latex-extra texlive-fonts-extra
```

### Other platforms

Install [TeX Live](https://www.tug.org/texlive/) and ensure `xelatex` is available on `PATH`. If a package is missing, install it with your distribution's TeX package manager.

Check the installation:

```sh
xelatex --version
```

## Build locally

The Makefile will dynamically update the `VERSION` in `Makefile` when the resume is being built. Simply run:

```sh
make
```

For example, the 33rd build in August 2026 produces:

```text
resume.pdf
versions/neil_patterson_v26.8.33.pdf
```

`resume.pdf` is the latest version intended to be checked in. Intermediate files are kept in ignored `build/`.

## Version convention

Versioned PDFs use a `vYY.M.R` calendar-build convention:

- `YY`: two-digit year
- `M`: current month without a leading zero
- `R`: build revision, starting at `1` and incrementing within that month

For example, `v26.8.33` means the 33rd generated build in August 2026. This is a calendar build identifier, not Semantic Versioning. Each `make` invocation automatically selects the next revision for the current month.

To remove intermediate files:

```sh
make clean
```

Edit `resume.tex`, rebuild, and inspect the generated PDF before sharing it.
